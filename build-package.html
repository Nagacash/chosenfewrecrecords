02 / Brand Brief & Art Direction

Brand Brief

The Label

Chosenfewrecords. Hamburg, Germany. Founded 2006 by Shortlord (Maurice Holda). Independent hip-hop and Caribbean-influenced music label — record label, publishing, and artist management. Recognised by the Hamburg Behörde für Kultur und Medien in the official Labelförderung Förderergebnisse (Hamburg cultural-funding registry). Distributed by Rough Trade (historical). Based at cf-records.com.

Shortlord

Born in French Guiana to a Kreolin mother and US-soldier father. Grew up on an army base near Frankfurt. MC, producer, label CEO. 1998 golden record (400k+ worldwide). 2000 chart run with The Prophets Empire ("The Fight," heavy video rotation). Albums: Da Crusade EP (2002), Heavensent (2007, Rough Trade), Street Tape (2009), Return of the Ancient One. Producer credit: Crew 7 "Shawty Wanna Ride" (2009). Features: Daddy Freddy (UK), Nneka (Nigeria). Roster/affiliates: I.Q. Gray, TLAC, Haji Brown, Jahrose, Seven 30, Warrior Rapper School. Connection to Hamburg's NAGA Club scene. Channel back up after YouTube strike — 244 videos, 3.06K subs.

Sound Identity

Hip-hop core × Caribbean/dancehall textures. Socially conscious lyricism + club energy in the same catalogue. Hamburg street meets diaspora heritage meets spiritual depth. Not trap, not mumble — seasoned independent rap with global range.

Hamburg Hip-Hop Caribbean Dancehall Fusion Independent Socially Conscious Since 2006 Rough Trade Era

Art Direction

Direction: "Hamburg Harbour Brutalism × Caribbean Heat"

Not the generic "dark rap website" with floating particles and neon gradients. This is a fully dark site — black base throughout, zero light sections. Think weathered, tactile, earned. Like a hand-stamped 12" sleeve with real history behind it.

Palette

  • #090909 — site background (all sections)
  • #111111 — card/surface background
  • #F0EDE6 — off-white body text
  • #FF6A00 — sodium orange (primary accent)
  • #C8A84B — dub-plate gold (secondary accent)
  • #1A3028 — Guyanese deep green (tertiary)
  • #888888 — muted grey (meta/labels)

Typography

  • Headlines: Archivo Black — condensed, heavy, all-caps
  • Body: Archivo Regular/Medium — readable, neutral
  • Mono / labels: Space Mono — tracking 0.15–0.25em
  • Oversized headline scale (clamp 36–96px)
  • Section labels: monospaced, spaced, orange
  • No thin weights anywhere

Texture & Motion

  • Halftone / offset-print dot pattern overlay (5–8% opacity)
  • Tape grain / 35mm film texture on hero images
  • Marquee ticker for release titles
  • Scroll-triggered fade-up reveals (framer-motion)
  • Hard grid — no rounded cards on primary surfaces
  • Audio-waveform SVG motif in footer/about
  • No glassmorphism, no floating orbs, no gradients
03 / Sitemap & Content Spec

Sitemap

/ Hero

Full-viewport. Logo (upload slot top-left). Headline: "Hamburg. Independent. Since 2006." One-line manifesto below in body text. CTA button → latest release. Right side: current featured release artwork (from Too Lost API). Marquee ticker scrolling below with all release titles.

/releases — Catalogue

Grid of release cards fetched from Too Lost GET /releases. Artwork, title, artist, release date, format tags. Click → detail view with tracklist (GET /releases/{id}/tracks), ISRC, UPC, streaming platform links. Filterable by year/format. ISR-cached, not called client-side.

/artists — Roster

Shortlord as flagship artist card — full-width, detailed. Below: roster grid with I.Q. Gray, TLAC, Haji Brown, Jahrose, Seven 30 (and room to add new signings as cards). Each card: name, photo placeholder, short bio, links to their releases.

/artists/shortlord — Artist Page

Full artist page. Bio (born French Guiana → Frankfurt army base → Hamburg). Discography timeline: Da Crusade (2002), Heavensent (2007, Rough Trade), Street Tape (2009), Return of the Ancient One. Notable credits: Crew 7, Daddy Freddy, Nneka. Press/accolades: Hamburg Labelförderung. Streaming links. Latest tracks from Too Lost API.

/videos — Archive

YouTube video reel. Curated selection of 12 real clips from the channel (real IDs listed in integration spec). Click-to-play with youtube-nocookie.com embed. Poster thumbnails. Lazy-loaded. GDPR-friendly (no iframe until user clicks). Phase 2: auto-pull from YouTube Data API.

/about — Label Story

20-year Hamburg independent story. Hamburg Speicherstadt aesthetic background image. Include: Hamburg Labelförderung recognition, Rough Trade distribution era, NAGA Club connection, Woodland 360 session series. German roots + Caribbean diaspora angle. Timeline component.

/demo — Demo Submission

Studio image background. Simple form: name, SoundCloud/link, genre, message. Server action sends to email. Bilingual DE/EN. Below the form: submission guidelines (no DM demos, link only, response within 4 weeks).

Footer

Logo. Social links: YouTube (@chosenfewrecords), Instagram, Spotify, Apple Music. Nav links. Imprint / Impressum (legally required, DE). Datenschutz / Privacy Policy (GDPR-required, DE). Copyright line. Language switcher DE/EN.

API INTEGRATION 1 — TOO LOST (RELEASES)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
Base URL: https://api.toolost.com/v1
Auth: OAuth 2.0 Bearer token (Authorization Code + PKCE flow)

CRITICAL SECURITY RULE: The Too Lost API MUST ONLY be called from Next.js
Server Components or Route Handlers — NEVER from client components.
The access token must live in env vars and never be exposed to the browser.

Token management:
  - Store: TOOLOST_CLIENT_ID, TOOLOST_CLIENT_SECRET, TOOLOST_REFRESH_TOKEN
    in .env.local / Vercel env vars
  - Create lib/toolost.ts with a getAccessToken() function that:
      1. POSTs to https://toolost.com/oauth/token with grant_type=refresh_token
      2. Caches the returned access_token in-memory with its expires_in value
      3. Returns the cached token on subsequent calls within the expiry window
  - Cache API responses using Next.js fetch cache with revalidate: 21600 (6h)
    so page views never burn API quota. Use next: { revalidate: 21600 } on
    every fetch call.
  - On the Free plan (5,000 calls/mo hard cap), the 6h ISR means at most 4
    server-side fetches per day per endpoint — well within quota.

Endpoints to implement:
  GET /releases           → /releases page grid
  GET /releases/{id}      → /releases/[id] page
  GET /releases/{id}/tracks → track listing on release detail
  GET /preferences/label  → label profile (name, artwork, bio)
  GET /preferences/artists → roster list

Response shape for releases (use for TypeScript types):
  data[]: { id, title, artist, artwork_url, release_date, upc, format,
            status, streaming_links: { spotify, apple_music, youtube_music,
            tidal, amazon_music, deezer } }

Fallback: if the API returns a non-2xx or times out, render a static
placeholder card that says "Releases loading…" rather than throwing a 500.
